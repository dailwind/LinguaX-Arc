# Contributing to LinguaX Arc

Thank you for your interest in improving LinguaX Arc.

## Reporting bugs
Open an [issue](https://github.com/dailwind/LinguaX-Arc/issues) and include:
- your device model and Android version (or browser, if running from source);
- the module you were using and the settings you chose;
- a small sample text that reproduces the problem, if you can share one.

## Suggesting features
Open an issue labelled **enhancement** that describes the research task you want to carry out.

## Validation studies
If you compare LinguaX Arc's output with another tool (AntConc, WordSmith, #LancsBox, Sketch Engine), please share your method and results in an issue. Validation reports are very welcome.

## Code contributions
1. Fork the repository and create a branch.
2. Make your change in `www/index.html`. The app must keep working fully offline: do not add calls to external servers or CDNs.
3. Open the page in a browser and check the module you changed.
4. Open a pull request that describes what changed and why.

## Support
Questions can be asked through GitHub issues. The maintainer aims to respond within two weeks.
